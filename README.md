## 🔥 Currently building

### CareCircle
A family sets up an elderly person’s medication schedule and appointments. The senior gets large-button reminders, and the family sees live whether each dose was taken and gets alerted when one is missed.

**Escalating alerts:** reminder, then a repeat, then a notification to a family member.
